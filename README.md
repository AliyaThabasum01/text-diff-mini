# 📝 Text Diff Mini

A lightweight Python CLI tool for comparing two text files and displaying their differences.

## Features

- Compare two text files
- Show added lines
- Show removed lines
- Detect identical files
- No external dependencies

## Run

```bash
python main.py
```

## Example

```text
First file: sample1.txt
Second file: sample2.txt

- Version 1
+ Version 2
+ New feature added
```

## Built With

- Python
- difflib
